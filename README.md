# Iris Flower Classification using Machine Learning

## Project Overview

This project uses Machine Learning techniques to classify Iris flowers into three species:

- Setosa
- Versicolor
- Virginica

based on sepal and petal measurements.

## Dataset

The Iris dataset contains 150 samples with four features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-Learn
- Jupyter Notebook

## Machine Learning Models

1. Logistic Regression
2. Random Forest Classifier

## Results

| Model | Accuracy |
|---------|---------|
| Logistic Regression | 93% |
| Random Forest | 90% |

## Conclusion

The Logistic Regression model achieved the best performance with 93% accuracy and successfully classified Iris flower species.
